# Eye of Chaos — عين الفوضى

موقع أولي متجاوب لمشروع «عين الفوضى / أسطورة الفوضى».

## التشغيل
افتح `index.html` في أي متصفح حديث.

## الهيكل
- `index.html` الصفحة الرئيسية والأقسام.
- `css/style.css` التصميم والوضع المظلم والتجاوب للهاتف.
- `js/app.js` القائمة، نافذة الفصول، ومحطة الأوامر.
- `assets/` للصور والخلفيات والصوتيات لاحقاً.

يمكن لاحقاً تحويل الأقسام إلى صفحات مستقلة وإضافة Backend وقاعدة بيانات ومصادقة ونظام ملفات سرية حقيقي.
